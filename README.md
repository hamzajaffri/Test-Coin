# HamzaCoin — Minimal PoW Cryptocurrency (Prototype)

⚠️ Educational Project: Ye ek simple cryptocurrency blockchain hai jo **Bitcoin ki tarah independent coin** hai (token nahi).  
Ye sirf learning aur testing ke liye hai, production-ready nahi hai.

## Features
- Independent blockchain (apna ledger, token nahi).
- Proof-of-Work (SHA-256).
- Adjustable difficulty & block target time.
- Wallets with ECDSA keys.
- Simple REST API via Flask.
- Mining support.
